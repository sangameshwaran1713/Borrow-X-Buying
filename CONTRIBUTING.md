# 🤝 Contributing Guidelines for Borrow-X-Buying

Thank you for contributing to **Borrow-X-Buying**!

## Development Setup

1. **Clone & Install Dependencies**:
   ```bash
   git clone https://github.com/sangameshwaran1713/Borrow-X-Buying.git
   cd Borrow-X-Buying/backend && npm install
   cd ../frontend && npm install
   ```

2. **Environment Configuration**:
   - Copy `backend/.env.example` to `backend/.env`.

3. **Running Services**:
   - Start Backend API: `cd backend && npm start`
   - Start Frontend Vite App: `cd frontend && npm run dev`

4. **Testing & Quality Checks**:
   - Run Backend Jest Test Suite: `cd backend && npm test`
